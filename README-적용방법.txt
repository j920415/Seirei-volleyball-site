세이레이 사계절 OST 플레이어 스킨 업데이트

포함 파일
- index.html: 최신 업로드 원본 그대로
- script.js: 최신 업로드 원본 그대로
- style.css: 최신 업로드 CSS에 플레이어 계절별 전체 스킨 적용

적용 방법
1. 기존 저장소의 index.html, script.js, style.css를 백업합니다.
2. ZIP 안의 세 파일로 저장소의 같은 이름 파일을 교체합니다.
3. 기존 audio 폴더와 images 폴더는 그대로 유지합니다. 이 ZIP에는 음원/이미지 파일이 포함되어 있지 않습니다.

변경 내용
- 플레이어의 크기, 위치, 레이아웃, 모서리, 컨트롤 배치는 유지합니다.
- 플레이어 영역의 배경, 테두리, 글자, 셀렉트 박스, 버튼 색만 계절별로 부드럽게 전환합니다.
- 봄: 벚꽃 핑크 / 여름: 세이레이 하늘색 / 가을: 따뜻한 앰버 / 겨울: 아이스 블루
- 음악 목록, 재생 로직, 홈페이지의 다른 기능은 최신 업로드 파일을 유지했습니다.
