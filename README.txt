SEIREI HIGH SCHOOL — SEVEN-TRACK OST WEBSITE UPDATE

Included:
- index.html, style.css, script.js: website with intro and seven-track OST player
- images/seirei-intro.svg: intro scene illustration
- audio/Summer-Court-Rhythm.mp3
- audio/Summer-Rally.mp3
- audio/春の試合前.mp3
- audio/Autumn-Court.mp3
- audio/Autumn-Afterglow.mp3
- audio/Snowlight-Memories.mp3
- audio/Snowy-Afternoon-Classroom.mp3

Install:
1. Back up your current repository files.
2. Replace index.html, style.css, and script.js in the repository root.
3. Keep images/seirei-intro.svg in the images folder.
4. Add/replace all seven MP3 files inside an audio folder in the repository root.
5. Commit the changes and wait for GitHub Pages to publish.

The intro music starts only after the visitor clicks ENTER. The player lets visitors select tracks, play/pause, skip tracks, and automatically advances when a track ends.
